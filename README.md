# lamonato.org

A small static site for Lamonato.

The interface uses a restrained, stacked textual grammar on a procedural grey
surface. IBM VGA 8×16 carries navigation and metadata; smaller sans-serif text
carries descriptions and diary thoughts.

## Run

Open `index.html` directly in a browser.

## Properties

- semantic HTML
- no JavaScript
- no analytics, forms, accounts, or advertising
- local font assets and procedural CSS texture
- relative internal links for local and GitHub Pages hosting

## Initial routes

- `/` — diary
- `/projects/`
- `/about/`
- `/contact/`
- `/information/`
- `/404.html`

## Typography

The live interface uses WebPlus IBM VGA 8×16 from the Oldschool PC Font Pack,
licensed under CC BY-SA 4.0. The original license and README are stored beside
the font in `assets/fonts/oldschool/`.

`type-test.html` remains as the local type study that informed the choice.
